SMART CROP WATER STRESS — V3

ملخص الإصلاحات:
- إصلاح مشكلة عدم تغير عبارة Waiting for data باستعمال getElementById لعنصر الحالة.
- إضافة رسوم تطور الحساسات، تطور الإجهاد المائي، والتشتت بين رطوبة التربة ونسبة اللون الأخضر.
- إضافة تحليل صورة RGB وحساب ExG وVARI والتصدير CSV.
- التحقق من المجال: نسبة اللون الأخضر بين 0 و1؛ لذا تُكتب 0.30 وليس 30.
- التمييز بين بيانات المحاكاة وبيانات القياسات التي يسجلها المستخدم.
- تصميم متوافق مع Android وملفات PWA تعمل بدون مكتبات خارجية.

طريقة تحديث GitHub Pages:
1. افتح مستودع GitHub الذي تستضيف فيه التطبيق.
2. ارفع كل الملفات الموجودة بجانب هذا README إلى جذر المستودع المستخدَم للاستضافة:
   index.html, app.js, manifest.json, service-worker.js, icon-192.png, icon-512.png
3. عند وجود الملفات القديمة، اختر استبدالها. احتفظ بنسخة من القديم عند الحاجة.
4. انتظر اكتمال نشر GitHub Pages ثم افتح رابط التطبيق من Chrome، وحدّث الصفحة.
5. إذا ظلت النسخة القديمة بعد التحديث، أغلق التطبيق المثبت وأعد تشغيله. عند استمرار المشكلة امسح ذاكرة التخزين المؤقت للموقع أو أزل التطبيق وثبّت النسخة الجديدة.

طريقة التجربة:
- القيم: Soil=42 / Green=0.30 / Temperature=25 / Humidity=46 / VARI=0.30
- اضغط Analyze measurements لرؤية مستوى الإجهاد والمؤشر.
- اضغط Start simulation لمشاهدة تطور المنحنيات خلال 10 أيام.
- افتح صورة للنبات لمعرفة RGB وExG وVARI؛ ستُدرج قيم RGB تلقائياً، وبعدها اضغط Analyze.
- يمكن حفظ القياسات في ذاكرة الجوال وتصدير CSV.

ملاحظات:
- جميع نتائج المحاكاة اصطناعية وتوضيحية وليست قراءات من حساسات حقيقية.
- نموذج التصنيف قائم على قواعد وليس نموذج AI مدرّباً أو قرار ري معاير.
- الربط المباشر بحساس ESP32 عبر http:// من موقع HTTPS قد يُحظر بسبب Mixed Content / CORS. يلزم HTTPS endpoint متاح وصلاحيات مناسبة.
